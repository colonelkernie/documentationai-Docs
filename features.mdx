## Route Scheduling and Optimization

Schedule routes in minutes using Laminar Copilot's intelligent optimizer. It considers factors like vehicle capacity, time windows, and real-time traffic to minimize costs and delays.

<Steps>
  <Step title="Create a Route" icon="plus">
    Navigate to the Routes dashboard in the app at `https://app.laminarcopilot.com/routes`.

    Add stops with addresses and priorities.
  </Step>
  <Step title="Optimize" icon="zap">
    Click Optimize. The system computes the best sequence.

````javascript
// Example API call to optimize
const response = await fetch('https://api.laminarcopilot.com/v1/routes/optimize', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_TOKEN', 'Content-Type': 'application/json' },
  body: JSON.stringify({
    stops: [
      { address: '123 Main St, City', timeWindow: '09:00-12:00' },
      { address: '456 Oak Ave, City', priority: 'high' }
    ]
  })
});
````
  </Step>
  <Step title="Confirm and Assign" icon="check-circle">
    Review the optimized route and save it for driver assignment.
  </Step>
</Steps>

<Callout kind="tip">
  Enable traffic integration for `<10%` better ETAs during peak hours.
</Callout>

## Driver Assignment and Management

Assign drivers based on location, skills, and availability. Laminar Copilot supports manual selection or automatic matching.

<Tabs>
  <Tab title="Manual Assignment" icon="user">
    Select drivers from the pool.

    <ParamField path="driverId" param-type="string" required="true">
      Unique driver identifier.
    </ParamField>

    <ParamField query="vehicleType" param-type="string" required="false">
      Filter by truck or van.
    </ParamField>
  </Tab>
  <Tab title="Auto Assignment" icon="zap">
    Let the system match drivers optimally.

````javascript
// Auto-assign API example
await fetch('https://api.laminarcopilot.com/v1/routes/{routeId}/assign', {
  method: 'POST',
  body: JSON.stringify({ auto: true })
});
````
  </Tab>
</Tabs>

## Audit Panel for Compliance Checks

The Audit Panel provides a centralized view of all compliance events. Track regulatory adherence, driver certifications, and vehicle inspections.

<Expandable title="View Audit Logs" default-open="true">
  Access the panel at `https://app.laminarcopilot.com/audit`.

  Filter by date, driver, or event type. Export logs as CSV for records.

  ```mermaid
  graph TD
      A[Route Start] --> B[Driver Check]
      B --> C[Vehicle Inspection]
      C --> D[Delivery Scans]
      D --> E[Route Complete]
  ```

</Expandable>

<ResponseField name="auditId" field-type="string" required="true">

<ResponseField name="complianceStatus" field-type="boolean">

## Real-time Tracking and Reporting

Monitor routes live with GPS updates every `{30s}`. Generate custom reports for performance analysis.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Fetch live tracking
  const tracking = await fetch('https://api.laminarcopilot.com/v1/tracking/{routeId}');
  const data = await tracking.json();
  console.log(data.currentLocation);
  ```
  ```python
  import requests
  response = requests.get('https://api.laminarcopilot.com/v1/tracking/{routeId}')
  data = response.json()
  print(data['currentLocation'])
  ```
</CodeGroup>
