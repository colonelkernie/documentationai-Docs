---
title: Shift Start Time Windows
description: >-
  Give a driver a second shift start time window so Dynamic Scheduler can assign
  them early and late routes without opening up the hours in between.
---
Every driver in your Driver Roster has a **Shift Start Time** window — the range of times they're willing to start a shift. You can now give a driver a **second window**, so a driver who will start early in the morning or late in the afternoon is available for both, without becoming available for all the hours in between.

Dynamic Scheduler assigns a driver to a route when the route's start time falls in **either** window and the driver's other preferences and limits are all met.

## Adding a second window

1. Go to the [**Drivers tab**](https://app.laminarcopilot.com/drivers).
2. Open the driver you want to edit and click **Edit**.
3. Fill in the second **Shift Start Time** row with a start and an end time.
4. Save the driver.

The second row is empty by default. Leaving it untouched saves the driver with a single window, exactly as before. To remove a window you've already saved, clear both of its fields and save again.

<Callout kind="alert" collapsed="false">
  A second window needs both a start and an end time. If you fill in only one of them, Copilot won't save the driver and will tell you which field is missing.
</Callout>

## How the windows affect scheduling

- Dynamic Scheduler treats both windows as equally acceptable. Neither one is preferred over the other.
- In the driver dropdown when you schedule a route, a driver whose second window matches the route counts as a start time match, just as if their first window had matched.

## Limits

- A driver can have at most two windows.
- Windows apply to every day the driver works. You can't set different times for different days — a driver's windows are the same across all of their **Work Days**.

If you're unsure how to set shift start time windows for your drivers, contact the **Laminar Copilot Support Team** for assistance.
