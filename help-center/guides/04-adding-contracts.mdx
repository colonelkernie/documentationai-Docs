## Adding Data to Copilot

In order for Laminar Copilot to automatically populate schedules and assist with everyday operations, your carrier's contracts, assets, and driver data must be added to Copilot.

---

## Adding Contracts

1. In Copilot, navigate to the **[Contracts tab](https://app.laminarcopilot.com/contracts)** (second tab from the top).
2. Navigate to **Amazon Relay > Managing Resources > Start Times**.
3. For every start time you see in Amazon Relay, **add the start time as a contract** in Copilot's Contracts page. Make sure to specify the type of route (**Solo 1** or **Solo 2**).

### Important Notes

- If you have **multiple of the same start time**, you'll need to add a contract for each one. For example, if you have two start times at 7:30, you should have two 7:30 contracts.
- If you **receive more start times from Amazon**, make sure to update your Contracts page. Your Contracts page in Copilot should always be consistent with your Start Times page in Relay.
