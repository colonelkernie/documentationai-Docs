## Adding Drivers

1. In Copilot, navigate to the **[Drivers tab](https://app.laminarcopilot.com/drivers)** (fourth tab from the top).
2. **Add all your drivers to your Driver Roster**, making sure you fill out all required fields:

   | Field | Description |
   |---|---|
   | **First Name** | Driver's first name |
   | **Last Name** | Driver's last name |
   | **Email** | Driver's email address |
   | **Phone Number** | Driver's phone number |
   | **Multiday Basis** | Obtainable from Amazon Relay |
   | **Type** | The type(s) of routes this driver should be assigned to |
   | **Stand By** | Mark `Yes` if the driver is part-time and should have lower priority for route assignments |
   | **Can Text** | Whether this driver can receive Copilot automated texts. *Ensure the driver has signed a legal agreement to receive automated messages before marking `Yes`.* |
   | **Status** | Whether the driver is available to be assigned to routes |

## Set Driver Preferences

For each driver, you have the option to set shift preferences using the following fields:

- **Shift Start Time** — The time range that the driver should start their shift.
- **Work Days** — The day(s) that the driver should start their shift.

> **Important:** The days and times entered as shift preferences are only for the **start of the shifts** — not the entire shift duration. Copilot uses the shift start time and day preferences to assign the right routes to your drivers.
