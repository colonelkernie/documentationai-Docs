## Getting Started

To begin using Laminar Copilot:

1. Sign up at `https://laminarcopilot.com`
2. Create a new workspace for your project
3. Invite team members using their email address
4. Click "New Document" to create your first doc
5. Organize docs with folders and tags

You're now ready to collaborate on documentation with Laminar Copilot!
