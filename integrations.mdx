## Overview

Laminar Copilot supports seamless connections to third-party tools, enabling you to automate workflows, receive notifications, and extend functionality. Use built-in integrations for quick setup, webhooks for real-time events, or the API for custom solutions. This guide covers setup steps and examples to integrate with your stack.

<Callout kind="info">
  All integrations require a valid API key from your Laminar Copilot dashboard. Generate one at `https://app.laminarcopilot.com/settings/api`.
</Callout>

## Webhook Setup

Webhooks notify external services about events like audit completions or route executions. Set them up in the dashboard under Settings > Webhooks.

<Steps>
  <Step title="Create Webhook" icon="plus">
    Navigate to Settings > Webhooks > New Webhook. Enter your endpoint URL, e.g., `https://your-webhook-url.com/webhook`.
  </Step>
  <Step title="Select Events" icon="zap">
    Choose events like `audit.completed` or `route.scheduled`.
  </Step>
  <Step title="Test and Save" icon="check-circle">
    Send a test payload and verify receipt before saving.
  </Step>
</Steps>

Example webhook payload:

<CodeGroup tabs="JSON">
  ```json
  {
    "event": "audit.completed",
    "timestamp": "2024-01-15T10:30:00Z",
    "data": {
      "auditId": "aud_123456",
      "status": "passed",
      "issues": 0
    }
  }
  ```
</CodeGroup>

## API Basics

Build custom integrations using the REST API at `https://api.example.com/v1`. Authenticate with `Authorization: Bearer YOUR_API_KEY`.

<ParamField header="Authorization" param-type="string" required="true">
  Bearer token for authentication.
</ParamField>

<ParamField query="auditId" param-type="string" required="false">
  Filter audits by ID.
</ParamField>

<Tabs>
  <Tab title="List Audits (cURL)" icon="terminal">
    ```bash
    curl -X GET 'https://api.example.com/v1/audits' \
      -H 'Authorization: Bearer YOUR_API_KEY'
    ```
  </Tab>
  <Tab title="JavaScript" icon="code">
    ````javascript
    const response = await fetch('https://api.example.com/v1/audits', {
      headers: {
        'Authorization': 'Bearer YOUR_API_KEY'
      }
    });
    const audits = await response.json();
    console.log(audits);
    ````
  </Tab>
  <Tab title="Python" icon="python">
    ````python
    import requests
    response = requests.get(
      'https://api.example.com/v1/audits',
      headers={'Authorization': 'Bearer YOUR_API_KEY'}
    )
    audits = response.json()
    print(audits)
    ````
  </Tab>
</Tabs>

<Response tabs="200">

  ```json
        "createdAt": "2024-01-15T10:00:00Z"
      }
    ],
    "page": 1,
    "total": 50
  }
  ```
</Response>
