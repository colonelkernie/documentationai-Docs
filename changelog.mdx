## Overview

Laminar Copilot releases new versions regularly to introduce features, fix bugs, and improve performance. Check this page for the latest changes that enhance your workflow automation and AI-driven insights.

## How to Check Your Version

Verify your installed version via the API:

<CodeGroup tabs="cURL,JavaScript">
```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.example.com/v2/version
```

```javascript
const response = await fetch('https://api.example.com/v2/version', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});
const data = await response.json();
console.log(data.version); // e.g., "1.5.0"
```
</CodeGroup>
