## Overview

Laminar Copilot releases new versions regularly to introduce features, fix bugs, and improve performance. Check this page for the latest changes that enhance your workflows in Copilot.

## Recent Releases

<Update label="2026-09-20" tags={["improvement"]}>
  ### GeoTab driver alerts in the Audit Panel

  The Audit Panel now flags drivers whose phone number or email don't match their GeoTab profile, so their actual route times can't sync. See the [Audit Panel](/help-center/solutions/the-audit-panel) article for details.
</Update>

<Update label="2026-09-18" tags={["feature","fix"]}>
  ### Solo 5 routes

  Copilot now supports Solo 5 (SO5) routes, which run up to 70 hours.

  ### Route editing fix

  We fixed a bug where adding a contract to a route that already had a driver and asset assigned cleared both assignments.
</Update>

<Update label="2026-09-12" tags={["feature","improvement","fix"]}>
  ### Two shift start time windows per driver

  Each driver can now have a second shift start time window, so a driver who will start early in the morning or late in the afternoon is available for both without becoming available for the hours in between. Dynamic Scheduler assigns a driver to any route whose start time falls in either window. See the [Shift Start Time Windows](/help-center/solutions/shift-start-time-windows) article for details.

  ### Driver Shift Summary export

  You can now download a CSV of your drivers' shift start and end times for the schedule week you're viewing, ready to reconcile against payroll. See the [Driver Shift Summary Export](/help-center/solutions/driver-shift-summary-export) article for details.

  ### Shift Patterns with a single driver

  You can now assign just one driver to a shift pattern and add the second one later, instead of having to fill both driver fields before you can save. See the [Shift Patterns](/help-center/solutions/shift-patterns) article for setup.

  ### Hours of service in the driver dropdown

  When you assign a driver in a route's Edit Drawer, the dropdown now shows how many hours each driver has already worked that week. Within each priority group, drivers are listed from fewest hours worked to most.

  ### Sync to Relay moved to the Command Center header

  **Sync to Relay** and its last synced time now sit next to **Notify Drivers** in the Command Center header, instead of in the top right of the Schedule tab. See the [Relay Integration](/help-center/solutions/relay-integration) article for details.

  ### Earlier routes filled first

  When two possible schedules score equally well, Dynamic Scheduler now prefers the one that fills the earlier starting routes.

  ### Relay Integration fix

  We fixed a bug where swapping drivers between two shifts left one of those shifts unassigned after syncing to Amazon Relay.

  ### Time Off Tracker fix

  We fixed a bug where, for workspaces outside Pacific time, a Time Off block starting at midnight appeared on the previous day in Calendar view.

  ### Breakdown tables fix

  We fixed a bug where the icon marking an unavailable driver, asset, or contract in the Breakdown tables had changed to an orange warning triangle. It's back to the red info icon.
</Update>

<Update label="2026-09-11" tags={["fix"]}>
  ### Route editing fix

  We fixed a bug where an invalidated asset couldn't be removed from a route, which blocked you from making other changes to that route, such as reassigning the driver.
</Update>

<Update label="2026-09-04" tags={["feature","fix"]}>
  ### Additional Shifts

  You can now let Dynamic Scheduler schedule extra shifts for your drivers during high volume weeks. Set an additional shift count in Company Settings and Dynamic Scheduler will schedule up to that many more shifts per driver. See the [Adjusting Overtime and Additional Shifts](/help-center/solutions/how-to-adjust-overtime-dynamic-scheduler) article for setup.

  ### Shift Patterns fix

  We fixed a bug where, when a shift pattern's own driver couldn't take a block, Dynamic Scheduler could hand that block to a fill-in driver whose work days or shift start time ruled the route out. Fill-in drivers now have to match their own shift preferences.
</Update>

<Update label="2026-08-31" tags={["improvement","fix"]}>
  ### SCV Extension syncs driver status

  The SCV Chrome Extension now also syncs driver status from Amazon Relay to Copilot, in addition to asset status and cab type. See the [SCV Chrome Extension](/help-center/solutions/scv-chrome-extension) article for setup.

  ### Audit Panel fix

  We fixed a bug where the Audit Panel incorrectly flagged an error for drivers that had been deleted from Copilot.
</Update>

<Update label="2026-08-25" tags={["improvement"]}>
  ### Texting improvements for unassigned assets

  24-hour shift confirmation and weekly shift texts now send to drivers on routes even when the route doesn't have an assigned asset.
</Update>

<Update label="2026-08-20" tags={["feature","fix"]}>
  ### Contract Breakdown Table

  We added a new Breakdown view where you can see your SO1 and SO2 routes broken down by contract.

  ### Audit Panel fix

  We fixed a bug where the Audit Panel incorrectly flagged drivers for not accepting routes that were Relay Rejected.
</Update>

<Update label="2026-08-18" tags={["feature","improvement","fix"]}>
  ### Shift Patterns

  SO2 contracts can now be configured with a 2-on-2-off shift pattern, in addition to the existing 4-on-4-off pattern. Dynamic Scheduler assigns the contract's two drivers automatically according to the selected rotation. See the [Shift Patterns](/help-center/solutions/shift-patterns) article for setup.

  ### Relay Integration sync errors

  We improved Relay Integration so that when a sync fails, you'll now see detailed error messaging explaining why.

  ### GeoTab integration fix

  We fixed the GeoTab integration so it properly pulls in certified route times.
</Update>

<Update label="2026-08-06" tags={["improvement"]}>
  ### More accurate 4-on-4-off scheduling

  We improved the 4-on-4-off scheduling algorithm to more accurately follow the 4-on-4-off pattern when additional routes deviate from it.
</Update>

<Update label="2026-07-30" tags={["feature"]}>
  ### Relay Integration

  Copilot can now sync driver assignments on your routes directly to Amazon Relay, so you no longer have to manually select them there. See the [Relay Integration](/help-center/solutions/relay-integration) article to get set up.
</Update>

<Update label="2026-07-23" tags={["feature"]}>
  ### GeoTab HOS Integration

  Copilot can now automatically pull actual start and end times for historic routes from GeoTab, with no manual entry required. See the [GeoTab HOS Integration](/help-center/solutions/geotab-hos-integration) article for setup.
</Update>

<Update label="2026-06-25" tags={["improvement"]}>
  ### Texting functionality improvements

  Weekly shift reminder and 24-hour shift confirmation texts now send to drivers even when a route has an invalidated tractor assignment.
</Update>

<Update label="2026-06-17" tags={["improvement"]}>
  ### More powerful Dynamic Scheduler

  We updated the Dynamic Scheduler algorithm to be more powerful and output the most optimal schedule possible. As a result, scheduling can take slightly longer, though it shouldn't take more than a few minutes.
</Update>

<Update label="2026-06-09" tags={["fix"]}>
  ### Fix on Maintenance Tracker

  The inability to edit time values of Maintenance Routes in the Maintenance Tracker on tablet devices have been resolved.
</Update>
