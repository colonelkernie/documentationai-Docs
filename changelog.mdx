## Overview

Laminar Copilot releases new versions regularly to introduce features, fix bugs, and improve performance. Check this page for the latest changes that enhance your workflows in Copilot.

## Recent Releases

<Update label="2026-05-09" tags={["feature","improvement","fix"]}>
  ## New Maintenance Tracker

  We now have <a href="https://app.laminarcopilot.com/maintenance_blocks" target="_blank" rel="noopener noreferrer">**Maintenance Tracker**</a>, a new page that allows you to manage and view all Maintenance Blocks for your assets. 

  Please use this tab to add new Maintenance Blocks and view all existing ones.

  ## **New Route Status: Cancelled by Amazon**

  You can now mark a route as “Cancelled by Amazon.” Copilot will treat the route as a non-active block but still display it in the Driver and Asset breakdown tables for visibility.

  ## **Bug fixing on Incremental Routes**

  We resolved a bug that limited which drivers could be assigned to Incremental Routes. Now all your drivers — regardless of their route type preferences — can be assigned to an Incremental Route.
</Update>
